AI, machine learning, and generative AI

Artificial intelligence is a broad name for computer systems that perform tasks we associate with intelligence. Machine learning is one way to build them: a model learns patterns from examples instead of following only hand-written rules. Generative AI uses learned patterns to create text, images, audio, or other content.

02 / 03

What happens during training?

Imagine showing a model many labeled photos of plants. It adjusts its internal settings when a prediction is wrong, then tries again. When it sees a new photo, it uses learned patterns to make a prediction. The quality and variety of the examples matter.

03 / 03

A useful limit to remember

A fluent answer is not proof that it is true. A model can produce a convincing error, especially when the question needs recent facts or information outside its training. Treat an AI answer as a starting point for checking.
