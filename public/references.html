Sources & credits

What shaped Fairylearn.

The sources behind every lesson, and the tools, fonts, images and AI help used to build the site.

Last updated October 29, 2026

On this page

  1. 01Learning content
  2. 02Tools and services
  3. 03Fonts
  4. 04Images and icons
  5. 05Generative AI disclosure

01Learning content

These sources support the learning modules. Each note says how it was used.

  1. Google for Developers, “What is Machine Learning?” ↗ (opens in a new tab)

    Used for the basic explanation of models, training examples, prediction and generation in Lesson 1.

  2. Google for Developers, “Introduction to Large Language Models” ↗ (opens in a new tab)

    Further reading for the generative AI and language model learning paths.

  3. OpenAI Help Center, “Prompt engineering best practices for ChatGPT” ↗ (opens in a new tab)

    Used for the clear task, context and revision technique in Lesson 2.

  4. UNESCO, “Guidance for generative AI in education and research” ↗ (opens in a new tab)

    Used for the education, privacy and human judgment considerations in Lesson 3.

  5. NIST, “AI Risk Management Framework: Generative AI Profile” ↗ (opens in a new tab)

    Used for Lesson 3’s emphasis on trustworthy information, bias and verifying AI outputs.

  6. OpenAI, “Text generation” ↗ (opens in a new tab)

    Further reading for the advanced building-with-models learning path.

  7. Technology Student Association, “Themes and Problems: Webmaster” ↗ (opens in a new tab)

    Used to match the 2027–2028 high school Webmaster challenge: AI fundamentals, practical tools, ethical use and progress tracking.

02Tools and services

  • Frameworks: no website builder, CMS, React, Vue or other front-end framework. The site is original HTML, CSS and JavaScript with a small Node.js server.
  • Accounts: Supabase Auth documentation ↗ (opens in a new tab) guided account access.
  • Personal lessons: OpenAI Structured Outputs documentation ↗ (opens in a new tab) guided the server-side personal lessons.

03Fonts

  • Inter ↗ (opens in a new tab) by Rasmus Andersson, used for all text. SIL Open Font License.
  • Fragment Mono ↗ (opens in a new tab) by Wei Huang, used for small labels. SIL Open Font License.

Both are served from this site, so no font requests go to other companies.

04Images and icons

  • Logo: supplied by the project team.
  • Watercolor illustrations: generated for this project with Google’s Gemini image model (Nano Banana Pro), all from one fixed style prompt kept in the project’s image script.
  • Icons and interface graphics: drawn in SVG and CSS for this project.

05Generative AI disclosure

OpenAI Codex assisted with planning, writing and revising code and learning text for this site. Anthropic’s Claude assisted with the site redesign, including the code and wording of these pages and the image prompts.

When a signed-in learner asks for a personal lesson, GPT writes it from their learning profile, and the site labels that lesson as made with AI.

The team must review the final work, verify factual claims and rights to assets, and describe its actual AI use in the official Resources and AI Reflection form.

Lesson explanations and examples were written for this project. They are not copied from the linked works.
